Звіт: Лабораторна_робота_3_Жуков_Михайло.docx
Покриття після запуску: coverage/index.html
Фактичні журнали Red / Green / Refactor: evidence/
Історія: git log --reverse --oneline

Фінальна перевірка: 60/60 тестів, 100% гілок (24/24).
У delivery.ts: 30 тестів, 13/13 гілок.
У parking.ts: 30 тестів, 11/11 гілок.

Правила доставки:
  Сума від 1000 грн: 0 грн, включно з експресом.
  До 5 кг: 50 грн; кожен розпочатий кг понад 5: +10 грн.
  Звичайний тариф обмежено 300 грн, потім експрес множить його на 2.
  Сума скінченна й >=0, вага скінченна й >0.
  Валідація виконується перед перевіркою безкоштовності.
  Округлення ваги до грама не вводилося; використовується JavaScript number.

Історія TDD створена локально з окремими кроками та їх фактичними
запусками, а потім опублікована як гілка 3. Вона має власний кореневий
коміт; попередня лабораторна залишається в гілці lab2-vitest.
У показовому прикладі тести округлення одразу проходили. Це записано
окремим комітом test, без імітації падіння Red.

Технічна адреса автора комітів lab3@localhost не є контактною поштою.
